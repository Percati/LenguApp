# Apps para mirar antes de definir la UI (oct 2026)

Lista de referencia, no de copia. Las apps cambian: mirá cómo están hoy. Orden: de lo más cercano al tono buscado (sobrio, de lectura, calmo) a lo que sirve de contraste.

| App | Plataforma | Qué mirar |
|---|---|---|
| Readwise Reader | Android, iOS, web | Tipografía de lectura, jerarquía clara, mucho aire. Es el tono "sobrio" más cercano a una ficha |
| Kindle | Android, iOS | Páginas que se leen, no que se tocan; temas claro, sepia y oscuro |
| AnkiDroid | Android | La línea base funcional de repaso: qué se puede quitar sin perder utilidad |
| Bear | iOS, macOS | Minimalismo cálido guiado por la tipografía; buen ejemplo de pocas decisiones muy cuidadas |
| Things 3 | iOS, macOS | Listas limpias, estrellas/marcas discretas, animaciones sutiles (útil para Guardados) |
| Day One | Android, iOS | Tono de diario personal: sensación de rutina semanal tranquila |
| Headspace | Android, iOS | Ilustración suave y color; para ver hasta dónde se puede ser amable sin ser infantil |
| Busuu | Android, iOS | Cursos de idiomas con nivel A1-C2: cómo muestran nivel y progreso |
| Duolingo | Android, iOS | **Contraste**: gamificación, mascota y racha. Sirve para saber qué NO queremos (la app no persiste progreso) |
| Apps de Google con Material 3 (Calendario, Keep, Reloj) | Android | Cómo se ve "bien hecho" dentro de Material You, que es lo que ya usa la app |

Dos sitios para mirar muchas pantallas de golpe: **Mobbin** (capturas de apps reales por patrón: filtros, listas, vacíos) y **m3.material.io** (guía y componentes de Material 3).

Qué mirar de cada una: tipografía, densidad (cuánto aire), color de acento, forma de los chips de filtro, cómo se ve una lista vacía y cómo se ve el modo oscuro. Con 3 o 4 favoritas anotadas se puede escribir el prompt de diseño.
